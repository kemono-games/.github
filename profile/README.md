## What we build

[**kemono.games**](https://kemono.games) is a community-driven index of furry and kemono games — a place to find what to play next, not just a list of links.

Every entry is curated by hand: release info, authors, platforms, download and play channels, screenshots, and tags. No spam, no dead mirrors left to rot.

## Open source

Bits and pieces of the infrastructure behind the site, released for anyone to use:

- [**image-optimizer**](https://github.com/kemono-games/image-optimizer) — on-the-fly image resizing, WebP/AVIF negotiation and GIF→MP4/WebM transcoding
- [**cf-image-proxy**](https://github.com/kemono-games/cf-image-proxy) — image proxy on Cloudflare Workers, built with Hono and @jsquash
- [**shorten-url**](https://github.com/kemono-games/shorten-url) — a small URL shortener running on Cloudflare Workers
